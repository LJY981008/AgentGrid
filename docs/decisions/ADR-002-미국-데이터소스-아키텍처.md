# ADR-002: 미국 주식 데이터소스 아키텍처

- **날짜**: 2026-06-16
- **상태**: 승인 (재무 정규화 도구는 [[ADR-005-재무-직접파싱]]가 부분 개정 — edgartools→직접 JSON 파싱. EDGAR 소스·filed=PIT·CIK 생존편향 결정은 유효)
- **결정자**: 사용자 / Claude 협의

## 맥락 (Context)

프로젝트가 한국주식 → **미국 주식 주력**으로 전환(사용자 결정). M1 데이터층을 미국 소스로 재설계해야 한다. 제약·요구:
- 금융 BLOCKING: 생존편향(폐지종목)·룩어헤드(시점 t엔 ≤t)·수정주가 통일·재현성.
- 사용자 방침: **무료 우선 검증 → 필요 시 유료**. 1인 비용 최소.
- 미국 무료 데이터엔 한국 FDR `KRX-DELISTING` 등가물이 없음(무료는 현재상장만) — 무료는 파일럿 한정, 생존편향·PIT는 유료/EDGAR 필수.
- 실측 근거: tech-researcher 워크플로우 3회([[2026-06-16-미국주식-데이터소스]]).

## 결정 (Decision)

**층별 소스 + 어댑터 추상화로 구성한다:**
- **가격**: 파일럿 = **Tiingo 무료** / 본격(M2) = **Sharadar SEP**(~$33~39/월, 폐지·closeadj). Polygon은 차선(배당미반영·PIT약).
- **재무**: **SEC EDGAR + edgartools**(무료·공식). `filed`=`disclosed_at`로 PIT, 원본 보존, CIK 무재사용으로 생존편향. `frames`는 횡단 탐색 전용(PIT 미보장).
- **결합**: 가격·재무 분리 적재 → **`merge_asof`/DuckDB ASOF JOIN**으로 PIT 조인(disclosed_at≤t).
- **어댑터**: `DataSource` Protocol 추상화 — 소스 교체 자유(Tiingo→Sharadar/EDGAR).
- **history**: 30년 고수 폐기 → 데이터 보장 시작연도(가격 1998~·재무 2009~)로 **유효구간 명시**.

## 검토한 대안 (Alternatives)

| 대안 | 판정 | 사유 |
|---|---|---|
| 재무 = **EDGAR** (채택) | ✅ | filed=PIT·원본보존·생존편향·무료·퍼블릭도메인. 정규화는 edgartools로 경감 |
| 재무 = SimFin | ❌ 기각 | **PIT 미충족(정정이 원본 덮어씀, SimFin 스스로 "not PIT" 인정)** + 구독종속(재현성 충돌) + 25년. 정규화만 줄이고 못 메울 결함 들임 |
| 재무 = Sharadar SF1 | △ 보류 | PIT 최강·1990~이나 유료(~$49~69/월). EDGAR 무료가 PIT 충족하므로 SF1 불요(→ 가격은 SEP 단독) |
| 결합 = **merge_asof** (채택) | ✅ | 결정적·인메모리·재현성. 1인 배치에 적합 |
| 결합 = RabbitMQ | ❌ 기각 | 1인·과거데이터·배치엔 과설계·비결정성·운영부담. M0에서 이미 제거한 유물. as-of 조인은 SQL/merge_asof 한 줄 |
| 정규화 = LLM 런타임 self-healing | ❌ 기각 | 무결성(오매핑→조용한 데이터 오염)·재현성(비결정) BLOCKING 위반. LLM은 오프라인 개발보조(사람 검토→git 커밋)만 |
| 가격 = Polygon 단독 | △ 차선 | flat files 강점이나 adjusted=split만(배당 직접계산)·PIT약·리브랜딩 품질보고. 보조/대체로만 |

## 결과 (Consequences)

- **얻는 것**: 무료로 파일럿(가격 Tiingo)+재무 PIT(EDGAR) 둘 다 커버. 본격 유료는 가격(SEP ~$33~39/월)만 → 비용 최소. 어댑터로 소스 락인 없음.
- **감수하는 것**: EDGAR 재무 구조화 2009~(17년, 소형주 2011~) — 유효구간 명시로 처리. ticker↔CIK 히스토리 자체 구축(생존편향 방어 핵심 인프라). edgartools 정규화 정확도 도입 전 검증. EDGAR User-Agent 식별정보 사용자 제공.
- **스키마 영향**: `financial(fiscal_period≠disclosed_at)` 설계는 EDGAR `filed`와 1:1로 **그대로 유효**. 종목 식별이 한국 6자리 코드 → **US ticker + CIK(안정 식별자)**로 변경 필요(db-architect 재설계). `Market` enum KOSPI/KOSDAQ → US 거래소.
- **재검토 트리거**: EDGAR 정규화 공수가 과도하거나 ~15필드 정확도 미달이면 Sharadar SF1($) 재검토. 30년 가격 풀히스토리가 필수가 되면 별도 소스.
