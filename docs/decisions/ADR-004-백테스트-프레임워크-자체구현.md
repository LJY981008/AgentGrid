# ADR-004: 백테스트 프레임워크 = 자체구현 (Decimal·DuckDB)

- **날짜**: 2026-06-17
- **상태**: 승인
- **결정자**: 사용자 / Claude 협의

## 맥락 (Context)

M2 백테스트 엔진 설계 시 프레임워크 선택이 미해결로 남아 있었다(stock-1st_plan §9-3: "vectorbt / backtrader / 자체구현 중 미결"). 기존 `src/stockpick/backtest/`는 `__init__.py`만 있는 빈 패키지로, 룰 검증 불가 → ranking `meta.validated=false` 영구 고정 · BacktestPage placeholder 상태. 프레임워크 선택이 금융 정밀도·생존편향·룩어헤드 가드·유지보수 모든 축에 영향을 미치므로 ADR로 확정한다.

핵심 제약:
- **금융 BLOCKING(float 금지)**: 거래 금액·수익률 누적의 부동소수점 오차는 순위 왜곡·수익률 오차로 직결. Decimal 강제(stock-1st_plan §4.1).
- **기존 코드화된 계약**: `rules/_scan.py`(룩어헤드 1차 SQL가드·DuckDB)·`rules/factors.py`(2차 메모리 가드·Decimal 내부계산)·`types.py`(Decimal 계약)가 이미 정밀도·DuckDB·룩어헤드 가드를 코드화했다 — 재사용 가능.
- **1인 개인 운영**: 과도한 추상화보다 투명성·완전 테스트·유지보수 단순성이 우선.

## 결정 (Decision)

**백테스트 프레임워크 = 자체구현 (Decimal·DuckDB 기반).** vectorbt·backtrader 모두 기각.

- 포트폴리오 계산은 `Decimal` 끝까지(거래비용·회전율·자산곡선). 통계(Sharpe·CAGR·MDD 등 연환산 무리수)만 `float` — 변환 1곳 격리(`metrics.py`).
- 저장소 읽기는 `backtest/ports.py` Protocol(DI) — `PriceSeriesPort`·`UniversePort`·`IdentityResolver`. 같은 코드가 무료 1년치 9종목(골격)·결제후 다년 전체유니버스(실전)를 구조변경 0으로 처리.
- DuckDB는 이미 `rules/_scan.py`에서 Parquet 스캔·룩어헤드 SQL 필터로 검증된 스택 — 백테스트 Parquet 스캔에 그대로 재사용.

## 검토한 대안 (Alternatives)

| 대안 | 장점 | 단점 | 기각 사유 |
|---|---|---|---|
| **vectorbt** | 벡터화 고속·시각화 내장 | **float 내부 계산**(Decimal 불가·정밀도 BLOCKING 위배)·블랙박스(룩어헤드·생존편향 가드 불투명) | 금융 정밀도 BLOCKING 위배. 내부 계산 감사 불가 |
| **backtrader** | 이벤트드리븐·풍부한 생태계 | 이벤트드리븐 복잡도(1인 일봉 리밸에 과설계)·float·외부 의존성 추가·Decimal 전환 불투명 | 1인 일봉 리밸에 과설계. float 기반으로 정밀도 BLOCKING 동일 |
| **자체구현** (채택) | Decimal 완전 통제·기존 rules/DuckDB 재사용·룩어헤드·생존편향 가드 완전 테스트·과적합 투명성 | 초기 구현 비용 | 제약 전부 충족. 기존 코드 재사용으로 구현 비용 상쇄 |

## 결과 (Consequences)

- **얻는 것**: Decimal 금융 정밀도 완전 보장. 룩어헤드·생존편향 가드를 코드 수준에서 완전 테스트(sabotage 패턴). 기존 `rules/`·`types.py`·`data/`·DuckDB 직접 재사용. 과적합 검증(IS/OOS·워크포워드·purge gap·decay ratio) 투명 구현. 외부 라이브러리 의존성 미추가.
- **감수하는 것**: 프레임워크 없이 직접 리밸런싱 루프·forward-return·폐지청산·비용 계산 구현. 초기 구현 공수 발생.
- **재검토 트리거**: 전체 유니버스(5,000+ 종목) 다년치 백테스트에서 성능 병목이 실측될 경우 vectorbt float→Decimal 래핑 가능성 재검토(단, 정밀도 BLOCKING 해소 전제).
