# ADR-010 — 백테스트 방법론 표준 교정: momentum 공정 측정 셋업 사전 동결

- 상태: 채택 (2026-06-25)
- 맥락: [[2026-06-25-백테스트방법론-전면교정]] · amends [[ADR-009-S6b-신뢰성게이트]] · 후속 of [[2026-06-24-A1p2-상한garbage-정제]]
- 검증: 다전문가(미국주식 퀀트·구현·적대비판) 토의·2회 리뷰(ACCEPT-WITH-RESERVATIONS) + Phase 0 실측 진단

## 맥락

A1p2(EODHD $1M sentinel 정제)로 게이트 핵폭발(−10^80)은 72자릿수 제거됐으나, 재실행 결과 **2차 폭발 잔존**(oos_excess e7·decay 7/10 폴드 >1). 3 전문가 독립 수렴: 폭발 지배원인은 microcap penny(트리거)가 아니라 **측정 셋업 자체(증폭기)** — `top-5(w=0.2) × per-ticker +19배 cap × 산술 복리 × 등가중-전체유니버스 벤치`.

**Phase 0 실측 진단(2026-06-25)**:
- **0a(증폭기 확정)**: 2000~2026 1패스서 pret 가 `0.2×19=3.8`(1 cap-hit)·`0.4×19=7.6`(2 cap-hit) 배수에 **정확히** 박힘. 상위 10% 기간이 분산 84% 지배. cap-hit=ret≥+1900%/월(정상 알파 아님). → 증폭기(per-ticker cap×집중×복리)가 root, microcap 빈도 아님.
- **0c(시총 불가)**: SEC EDGAR shares 커버율 ≈0.01%(financials 9 cik 파일럿) → 시총 필터·시총가중 벤치 **불가** → ADV 프록시.
- **0d(기간)**: pre-2000 생존편향(1962=27티커·폐지 pre-1995≈0·2000=10,222 급증) → 신뢰구간 = 폐지 완비 **2000~**.

momentum(JT 2001류)은 잘 문서화된 강건 팩터이나, 현 비표준 셋업으론 공정 측정 불가. 표준 퀀트(JT 2001·CRSP·Russell)로 교정해 **공정 측정** → 정직한 validated 판정.

## 결정 — 방법론 일괄 동결 (게이트 통과여부 보기 전·pre-registration)

### R1 방화벽 (정직성 핵심·BLOCKING)
Phase 0 진단은 방법의 **종류**(폭발=버그/구조·시총=가용/불가·기간=신뢰구간)만 결정. **모든 수치 임계는 외부 시장원칙으로 동결, 진단 분포로 고르지 않는다.** 진단 보고 "±80%가 excess 예쁘다" 선택 = 결과-튜닝(금지). 진단=계측-수정(망원경 보정), 임계-튜닝=p-hacking(금지). 임계 변경 시 ADR 갱신 + 사유 기록.

### ADR-009 게이트 기준 amendment
- **G-3 변경**: 벤치를 동일비용·유동성필터·decile 기준으로 교정. **집계는 전-fold OOS 초과>0 유지**(보수·loosening 아님 — 전-fold 가 가장 정직·통과 강요 회피). 벤치 공정화·decile 만 변경, 임계·집계 불변.
- **G-2·G-6 decay**: decile·clip 셋업서 재측정(임계 0.5 불변). G-1·G-4·G-5·G-7·G-8 불변.
- 신규 config 필드(수익처리·portfolio·유동성)는 전부 `fingerprint` + `compute_rule_signature` 포함(동결 우회 차단·period_return_cap 동류).

### R4 — 검증 룰(decile) ≠ 운영 Top5
게이트는 **decile momentum** 을 검증. 사용자 실투자 **Top5 = 검증된 decile 의 상위 부분집합**(같은 momentum score·top decile ⊃ top5). 논리 다리: decile 이 robust 하면 그 상위 5종목도 같은 시그널 방향 상속(단 분산↑·Top5 robustness 별도 미보증·caveat). flip signature = decile params(운영 Top5 요청도 decile signature 로 매칭).

## 근거 / 대안 기각

- **유동성 필터-only(원안)** 기각: 0a 가 증폭기를 root 로 확정 → 필터는 cap-hit 빈도만 줄이는 band-aid(정상 종목 급등에 다음 폭발).
- **시총가중 벤치 / 시총하한** 기각: 0c 데이터 불가(SEC shares ≈0%). ADV 프록시로 대체.
- **per-period 로그합산 병용** 보류: clip-only 가 증폭기 제거에 충분(최소개입·이중보수 회피). 게이트 후 잔존 폭발 시 재고.
- **G-3 집계 완화(과반+누적)** 기각: 전-fold 유지가 보수·정직(완화=통과 강요 의심). 표준이 누적을 쓰나, money BLOCKING 엔 엄격이 안전 오차방향.
- **1962~2026 전구간** 기각: 0d 생존편향.

## 정직성 / 가드
- **pre-registration**: 위 전부 동결 후 게이트 1회(패치-재실행 루프 금지·OOS 오염). 미수렴/fail → 정직 노출(validated=false 유지).
- 룩어헤드(≤t)·생존편향(시점별 멤버십·per-bar·MasterUniverse)·과적합(R1 방화벽·rule_signature)·결과결정성(bit-identical).
- momentum 명백 fail(깨끗한 측정 후) → 그때 다팩터 피벗 정당(지금 피벗=인프라버그를 룰 무알파로 오진).
