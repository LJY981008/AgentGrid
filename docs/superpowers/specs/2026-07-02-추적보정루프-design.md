## 3. 측정 규약 (전문가 blocking 반영 — 핵심)

### 3.1 수익률 척도
- **4계열 전부 price return, v1 통일.** 배당 미반영을 화면·API(`return_convention: "price"` 필수 필드)에 명시. 근거: 실보유는 배당 현금흐름 기록이 없어(v2) adjusted(=분할+배당 혼합) 벤치와 섞으면 실보유가 구조적으로 뒤처지는 **기울어진 저울**이 된다.
- **가격 = raw close + SPLIT 이벤트 정규화**(`N_t = raw_t × Π ratio(effective_on ≤ t)`). `adj_factor` 는 분할+배당 혼합(`data/_adjust.py` 실측)이라 **수량·평단·price return 어디에도 사용 금지**. 증분 수집 vintage 혼합 문제도 이벤트 방식이 근본 해소.
- **일별 chain-linked TWR** 공통 척도: `r_d = V_d / (V_{d-1} + F_d) − 1`. `F_d` = 당일 외부 현금흐름(입출금·start-of-day 효력). BUY/SELL 은 내부 이체(현금↔주식·F 불포함). 분모 0(미펀딩) → r=0, 분모 <0 → 측정불가 오류.

### 3.2 비교 계열 (4 + 파생 2)
| 계열 | 정의 |
|---|---|
| ① 실보유 | 전역 원장(수량×raw close+현금) 일별 TWR |
| ② Top5 등가중 모델 | 확정 Top5·스냅샷 앵커일 고정 가중·드리프트(리밸 없음)·체결 무관 |
| ③ Top20 등가중 모델 | 스냅샷 Top20 전체·동일 방식 — 룰추천 그대로 |
| ④ SPY | 벤치(1종목 특수화) |
| 선택효과 | ②−③ (수동 압축의 부가가치) |
| 실행효과 | ①−② (체결 타이밍·슬리피지·현금드래그) |

보조: MDD(계열별)·종목별 기여도(달러 P&L = MV변화+순거래현금 — 평단 규약 불요)·거래별 슬리피지(체결가 vs 당일 종가)·히트레이트(Top5 중 모델수익 >0)·**누적 pick N<20 동안 "판정 유보" 라벨 고정**(월 5종목 표본은 라운드당 판정 불가 — 노이즈로 룰 갈아엎기가 이 루프 최대 실패모드).

### 3.3 원장·시점 규약
- **포지션 원장 = 종목 전역**(라운드 무관). round_id = 리포팅 라벨. 라운드 open 시 carry-in 스냅샷(종목·수량·앵커가) 자동 동결 — v1 첫 라운드는 빈 배열.
- 일중 순서(결정성): SPLIT(장 시작) → 외부 현금흐름 → trade(id 순) → 평가(종가). 불변식: positions ≥ 0·cash ≥ 0(BUY 초과 = 422·입금 선행). 단수주 Decimal 허용(비정수 분할·UI 고지).
- **공통 as-of** = 활성 종목만 min(max(trade_date)). 비활성 = `listing_status='delisted'` OR max_date < 후보−5거래일. 폐지/영구결측 = 마지막 유효가 청산 → 잔여 현금 0%·재분배 금지(백테스트 폐지 규약과 동형 — 루프 내 생존편향 차단). 일시 결측 = 직전가 carry-forward.
- sanity 게이트: 가격 ≤0 등 오염(G-7 계열) → 해당 종목 "측정불가" 표시(조용한 왜곡 금지).

### 3.4 정직성·불변성
- top20_snapshot 에 rule_signature·validated·G-7 판정 요약 + **앵커일 raw close 동결**(재현성) + vintage 메타(price as-of).
- close: 신선도 게이트(as-of 가 5거래일 초과 stale → 409 "수집 먼저") + 구조화 회고 필수 + performance_snapshot 동결. **close 후 해당 라운드 거래 void 금지**(409 — 동결 발산 차단).
- GET performance 는 항상 재생 기반. closed 라운드는 동결값과 재계산 괴리 시 divergence 플래그(덮어쓰기 금지).
- 정정 = soft-void(voided_at·void_reason·append-only·물리 삭제/수정 금지) + void 후 전역 재생 재검증(후속 SELL 음수화 → 거부).
