> 결정 = [[ADR-001-마이그레이션-도구-alembic]]·[[ADR-002-미국-데이터소스-아키텍처]]. 현황 = [[PLAN_STATUS]].

## 1. M1 "완료" 정의

단순 적재 아님. **백테스트가 신뢰할 단일 진실원본(Parquet 1차 + PG18 서빙) + 데이터 신뢰성 리포트 전항목 PASS**. PASS 전 M2 금지.

## 2. 데이터 소스 (미국 — 실측 확정, 착수 시 pip 재실측) — [[ADR-002-미국-데이터소스-아키텍처]]

| 층 | 소스 | 비용 | 실측 |
|---|---|---|---|
| 가격(파일럿) | **Tiingo 무료** | $0 | 공식 REST+Python, 50/h·1000/day·500종목/월. raw close+adjClose+분할/배당 동시 → 원주가+adj_factor 직결 |
| 가격(본격·M2) | **EODHD** ([ADR-003](../decisions/ADR-003-M2-가격소스-EODHD.md)) | $19.99/월 | raw OHLC + adjusted_close(split+배당) 분리→adj_factor 모델 직결, US폐지 2000~, Linux REST·벌크. (Sharadar SEP는 데이터 최상이나 가격 불투명·대안) |
| **재무** | **SEC EDGAR + edgartools** | $0 | `companyfacts` 각 fact의 **`filed`=공시일** → `disclosed_at` PIT. 폐지 filing 영구보존·CIK 무재사용=생존편향. `frames`는 횡단 탐색 전용(PIT 미보장). edgartools 5.36.0 정규화 |

**핵심 리스크 (BLOCKING)**:
- 미국 **무료엔 폐지종목 소스 없음**(한국 FDR 등가물 부재) → 무료 파일럿은 현재상장 골격만, 생존편향은 유료/EDGAR에서.
- EDGAR 구조화 재무 **2009~만**(소형주 2011~, 실질 17년) → history 유효구간 명시(§6). ticker↔CIK 히스토리 자체 구축(ticker 재사용 함정).
- 가격·재무 결합 = **`merge_asof`/DuckDB ASOF JOIN**(disclosed_at≤t). RabbitMQ·LLM 런타임 정규화 기각(ADR-002).
**종목 식별 변경**: 한국 6자리 코드 → **US ticker + CIK(안정 식별자)**. `Market` enum KOSPI/KOSDAQ → US 거래소(NYSE/NASDAQ/AMEX). §3 stock 스키마·`types.py` 재설계 필요(db-architect, B 단계).
**미실측 잔존(코드 전 확인)**: Tiingo 무료 한도 실동작 / edgartools ~15필드 정규화 정확도 / EDGAR ticker-CIK 히스토리 인프라.

## 3. 저장 스키마

> ⚠️ 미국 전환(ADR-002): 종목 식별 = **CIK(안정·영구·무재사용) + ticker(가격 키·시변·재사용)**. ticker 단독 키 금지(폐지 후 ticker 재취득 시 오조인=생존편향 누수). 가격(daily_bar)은 ticker 키, 종목 마스터·재무·랭킹의 안정 조인은 CIK. `Market` ENUM(KOSPI/KOSDAQ) → `Exchange` ENUM(NYSE/NASDAQ/NYSE_AMERICAN/NYSE_ARCA/BATS/OTC). 계약 = `src/stockpick/types.py`(B-contract 완료).

- **Parquet(1차 진실원본, DuckDB 백테스트 스캔)**: Hive 파티션 `exchange={NYSE|NASDAQ|...}/year={YYYY}/`, 파일은 `(ticker, trade_date)` 정렬, zstd, row-group ~128MB. 폐지종목 동일 레이아웃 포함(분리 금지 — 스캔 누락). ⚠️ ticker 재사용 구간은 백테스트 시 ticker_history 로 CIK 해소 후 스캔(파티션 키 ticker 만으로 동일성 가정 금지).
- **PostgreSQL 18(운영 서빙)**: 8테이블(ticker_history 추가)
  - `stock`(**cik PK**, ticker=현재 심볼, name, exchange ENUM, listed_at/delisted_at nullable=현역/폐지일, is_etf_or_spac) — 폐지 DELETE 금지, 합집합 UPSERT. cik 가 안정 PK 후보(영구·무재사용)
  - `ticker_history`(**PK(cik, ticker, valid_from)**, valid_to nullable) — ticker↔CIK 시점별 매핑. ticker 재사용(폐지 후 타사 재취득)·심볼 변경(M&A·리브랜딩) 대응. 가격(ticker 키)→종목(cik) 조인의 **PIT 해소 키**: 가격 trade_date 가 어느 cik 의 ticker 였는지 시점으로 결정. 누락 시 ticker 재사용 종목이 조용히 합쳐짐(생존편향 누수) → BLOCKING
  - `daily_bar`(**PK(ticker, trade_date)**, 원주가 numeric + adj_factor + source, RANGE 파티션 by year + BRIN(trade_date), OHLC CHECK 정합) — 가격 소스 키가 ticker. cik 직접보관 대신 ticker_history 로 조인(이력 정확성)
  - `financial`(**PK(cik, fiscal_period, disclosed_at)**) — cik 키(EDGAR companyfacts 의 CIK 와 1:1). **`fiscal_period`(회계기간)≠`disclosed_at`(EDGAR `filed`=공시일) 분리, PIT 조회는 `disclosed_at<=t`**(룩어헤드 차단), 정정공시 보존. 이 설계는 미국 전환 후에도 그대로 유효(EDGAR filed 와 1:1, ADR-002)
  - `rule_version`(params jsonb·backtest_metrics), `top_entry`(**cik 앵커**+ticker, as_of_date PIT, factors jsonb, FK→rule_version) — 랭킹·추적은 cik 기준(ticker 재사용 오조인 방지)
  - `investor_trade`·`short_sale`(선택 보강) — 미국 등가 소스 확정 시(보류)
- 마이그레이션: **alembic**([[ADR-001-마이그레이션-도구-alembic]]) — 파티션/BRIN/ENUM/CHECK/JSONB 는 raw SQL.
- 도메인 계약: `src/stockpick/types.py` — Stock(cik+ticker)·DailyBar(ticker 키)·TopEntry(cik 앵커)·`Exchange` StrEnum·가격 **Decimal**(float 금지)·`adj_factor`(S1·B-contract 완료). `DataSource` Protocol = `src/stockpick/data/source.py`(소스 교체 추상화, 폐지 포함 유니버스).

## 4. 작업 순서 (파일럿 우선 — 점진 도입)

- **S0** 결정 확정·ADR ✅ (본 문서·ADR-001)
- **S1** 도메인 계약 정밀도 교정(float→Decimal, adj_factor) ✅
- **S2** 종목마스터 적재 — 코스피/코스닥 현행 + KRX-DELISTING 폐지종목 **합집합 UPSERT**(DELETE 금지). 컬럼은 실호출 실측.
- **S3** 파일럿 파이프라인 — 10~15 표본(대형주·액면분할·코스닥·폐지 2~3·신규상장)으로 FDR 일봉+pykrx 보강 → Parquet 저장. 1초 지연·지수백오프·체크포인트·멱등 UPSERT, 모든 행 source/ingested_at.
- **S4** 파일럿 검증 게이트 — 폐지종목 폐지일까지 적재, 액면분할(삼성전자 2018 50:1 등) 수정주가 점프가 이벤트로 설명됨 교차검증 PASS. pytest 픽스처/모킹(라이브 금지).
- **S5** 전체 유니버스 벌크 — 파일럿 골격 확장, 부분실패 재개(멱등), 적재 시점 스냅샷 고정.
- **S6** 데이터 신뢰성 리포트·게이트 판정 — 전항목 PASS 시에만 M1 완료 선언.

## 5. BLOCKING 가드 (코드/테스트/스키마에 물리 봉인)

- **생존편향**: 폐지 합집합 UPSERT만 허용·DELETE 금지. `delisted_at` 로만 폐지 표현. 게이트: 폐지종목 수 하한·폐지일까지 일봉 보존·미확보분 정량 고지.
- **룩어헤드**: `financial` 의 `fiscal_period`≠`disclosed_at`, PIT 조회 `disclosed_at<=t`. 가격은 `trade_date<=t`. 게이트: `disclosed_at` 누락 0.
- **수정주가 통일**: 단일 소스(FDR adjusted) 기준, 원주가+`adj_factor` 적재(원본 불변). 분할 표본 ≥10 교차검증 PASS.
- **재현성**: 적재 시점 스냅샷, source/ingested_at 기록, 동일 입력 재적재 시 동일 결과(멱등).
- **정밀도/정합**: 가격 Decimal/numeric, OHLC CHECK, 폐지종목 종가 0·-100% 경계값 필터.
- **테스트**: 픽스처/모킹만(라이브 데이터 차단), ruff+mypy(strict)+pytest 자동(post-work-check), src 변경 커밋 work-history 강제.

## 7. 미해결 (M2+ 이월)

- `adj_factor` PIT 안전성: 누적조정계수는 미래 분할 반영 → 절대 수정가 비교 시 미세 룩어헤드. 수익률(인접일 비율)만 쓰면 무해. M2 가 절대가 비교하면 `adj_event`(분할/배당 이벤트일+비율) 테이블 분리.
- daily_bar↔stock FK 강제 여부(생존편향 물리방어 vs 적재 순서 충돌) — 적재 전략 확정 후.
- RANGE 파티션 운영: pg_partman vs 수동(1인 운영이면 수동 단순) — devops 조율.
- 재무 `disclosed_at` 정밀도: pykrx 일자 스냅샷이 실제 공시일 부정확 가능 → OpenDART 공시일 vs 보수적 시차 근사(미해결 #1 연동).
- Parquet↔PG 동기·갱신주기(미해결 #6 연동).
- D2(30년 풀 vs 단축): 파일럿에서 1990년대 신·구 경계 품질 실측 후 판단 — 게이트 미달 시 '백테스트 유효구간'을 데이터 보장 시작연도로 명시.
