## 재무 데이터 — SimFin 기각, EDGAR 채택

**SimFin 검증 결과 기각**: 생존편향만 충족. **PIT 미충족(결정타)** — 표준셋이 정정공시 시 원본을 최신값으로 덮어써 SimFin 스스로 "not point-in-time" 인정 → 룩어헤드. + 구독종속(해지 시 삭제 의무, 재현성 충돌) + 25년(30년 미달) + SDK 18개월 방치. 정규화 공수만 줄이고 못 메울 결함을 들임.

**EDGAR 채택** (무료·공식·퍼블릭도메인):
- `data.sec.gov/api/xbrl/companyfacts/CIK{10}.json` — 각 fact에 **`filed`(공시일)** → `financial.disclosed_at` 직결, 룩어헤드 회피. **원본 보존**(정정도 별 fact)
- 폐지회사 filing 영구보존(1994~) + **CIK 무재사용** → 생존편향 회피
- ⚠️ `frames` API는 PIT 미보장(last-filed) → **횡단 탐색 전용**, 적재는 companyfacts/concept의 filed별 원본 fact
- 정규화: **edgartools 5.36.0**(2026-06-09, MIT, 매우 활발) — standardize(횡단 표준재무·statement stitching)·rate-limit·User-Agent 자동. 자체 Fallback Dictionary 부담 최대 경감
- 한계: XBRL 구조화 재무 **2009~**(소형주 2011~, 실질 17년) / ticker↔CIK 히스토리 자체 구축 필요(ticker 재사용 함정) / edgartools ~15필드 커버 정확도 미검증(도입 전 검증)

## 아키텍처 결정 (요약 — 상세 ADR-002)

- **이종 비동기 결합**: 가격(일배치)·재무(분기/연배치) 분리 적재 → **`merge_asof`/DuckDB ASOF JOIN**으로 PIT 조인(disclosed_at≤t). ❌ **RabbitMQ 기각**(1인 배치엔 과설계·비결정성, M0에서 이미 제거한 유물)
- **정규화 AI**: ❌ 런타임 self-healing 기각(무결성·재현성 BLOCKING 위반). LLM은 오프라인 개발보조(새 태그 제안→사람 검토→git 사전 커밋)만
- **어댑터 추상화**: `DataSource` Protocol — Tiingo 구현 시작, 유료/EDGAR 교체 자유(소스 락인 방지)
- **history 재정의**: 30년 고수 안 함 → 가격 SEP 1998~·재무 EDGAR 2009~ 데이터 보장 시작연도로 **유효구간 명시**
- **팩터(가치 vs 성장)**: 선험적 고정 안 함(과적합 금지) → M1은 필드 superset 수집, 가중치는 M2 백테스트가 결정
