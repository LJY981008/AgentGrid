# 추적·보정 루프 (M4) — 월 라운드 운용 기록·성과 추적·구조화 회고 (구현 플랜)

## Context — 왜

기획(stock-1st_plan §5)의 마지막 미구현 축. validated 룰 0개(momentum·momentum×ROE 정직 fail) 상태에서 수익의 현실 병목 = 알파가 아니라 **피드백 없는 운용** → 목적은 운용 규율·실측 피드백(알파 아님). 사용자 결정: 라운드 단위·PWA 폼 수동입력·벤치 SPY+Top20등가중·구조화 회고. **6전문가 크리틱 전원 REVISE-GO**(blocking 25건) 반영 + Plan 에이전트 모순 10건 해소 완료. 3 Explore 실측 기반.

## 확정 설계 핵심 (전문가 blocking 반영)

- **수익률**: 4계열 전부 **price return v1 통일**(배당 미반영 명시·`return_convention` 필드) = **raw close + SPLIT 이벤트 정규화**. adj_factor 는 분할+배당 혼합(`_adjust.py` 실측)이라 수량/평단 보정에 사용 금지. **일별 chain-linked TWR** 공통 척도: `r_d = V_d/(V_{d-1}+F_d)−1`, F=외부 현금흐름(start-of-day), BUY/SELL 은 내부 이체. 분모 0 → r=0, 분모<0 → 측정불가.
- **계열 4+파생 2**: ①실보유(원장×raw close+현금) ②Top5 등가중 모델(스냅샷 앵커 고정가중·드리프트·리밸없음) ③Top20 등가중 모델 ④SPY. 선택효과=②−③·실행효과=①−②. +MDD(float)·종목별 기여도(달러 P&L=MV변화+순거래현금 — 평단규약 불요)·슬리피지(체결가 vs 당일종가)·히트레이트·**누적 pick N<20 "판정 유보" 라벨 고정**.
- **원장**: 종목 **전역**(round=리포팅 라벨). 일중 순서 규약: SPLIT(장시작)→외부현금흐름→trade(id순)→평가(종가). 불변식 positions≥0·cash≥0(BUY 초과=422·DEPOSIT 선행). SELL 검증=전역 재생. 단수주 Decimal 허용(비정수 분할·UI 고지).
- **공통 as-of**: 활성 종목만 min(max(trade_date)) — 폐지 종목 제외(비활성=`listing_status='delisted'` OR max_date<후보−5거래일). 폐지=마지막 유효가 청산→현금 0%·재분배 금지. sanity 게이트(가격≤0)→종목 측정불가 표시.
- **SPY**: stock 마스터 편입 금지(유니버스는 이미 common stock 전용 — 실측) → **`base_dir/"benchmark"` 서브트리**에 `write_daily_bars(base_dir/"benchmark", exchange=NYSE_ARCA)` 재사용 격리. 거래일 그리드=SPY 시계열(NYSE 프록시).
- **정직성**: top20_snapshot 에 rule_signature·validated·G-7 요약 동결 + `anchor_close` 동결(재현성). UnvalidatedWarning 상시(fail-safe). 스냅샷 JSONB 에 vintage 메타(price as-of). close 후 라운드 trade void 금지(409 — 동결 발산 차단). GET performance 는 항상 재생 기반(동결값과 괴리 시 divergence 플래그).
- **정정**: soft-void(voided_at·void_reason·append-only·물리삭제 금지)+void 후 전역 재생 재검증(후속 SELL 음수화 거부).
- **v2 이연**: 배당 현금흐름·total return 승격·CSV 임포트·룰버전 테이블·실현/미실현 분해.
