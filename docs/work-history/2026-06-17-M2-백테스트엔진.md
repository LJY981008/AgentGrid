### Context (왜)

stockpick의 모든 룰은 **백테스트 검증 전 알파 아님**(stock-1st_plan §4.1 BLOCKING, ranking `meta.validated=false`). 현재 `src/stockpick/backtest/`는 `__init__.py`만 있는 **빈 패키지** — 룰엔진(M2 수직슬라이스)·M3 API/webapp은 됐으나 검증 모듈이 비어 BacktestPage가 placeholder, validated 영구 false.

### Gemini 외부 리뷰 평결

5개 전부 타당, 2개 위치 정밀화:
1. **어댑터 레이어** — 채택+**수정**: backtest는 라이브 API가 아니라 **Parquet 저장소를 읽음** → `data/source.py`의 `DataSource`(수집용) 재사용 아니라 `backtest/ports.py` **읽기 포트** 신설. (API DataSource 재사용 시 매 백테스트 재페치·rate-limit·비재현)
2. **Config 해싱** — 채택: `BacktestConfig.fingerprint()` canonical(Decimal normalize·sort_keys)→sha256. float 필드 금지.
3. **폐지 Mocking** — 채택: 무료데이터 폐지 0건 → 합성 폐지 주입 `FakeUniversePort`로 생존편향 가드 발동 증명(골격 핵심 자산).
4. **청산 룰** — 채택+**수정**: `delisting_recovery_rate` config 파라미터, 위치는 `engine` 수익이벤트(costs 아님). 단 청산도 거래비용 조건부 적용(-100% 휴지는 비용 0).
5. **Decay Metric** — 채택+**수정**: OOS/IS Sharpe 방어율, 단 `IS_Sharpe>ε` 게이트 통과 시에만 산출(IS≤0이면 룰 기각 별도 플래그, 분모 폭발 방지).

### 핵심 계약

- **`BacktestConfig`**: strategy_name·top_n·lookback_days·skip_recent_days·rebalance_freq·cost_bps(Decimal)·delisting_recovery_rate(Decimal)·group_by_exchange·start·end·trading_days_per_year(=252 명시)·`fingerprint()`. **전 필드 Decimal/int/date/str/Exchange — float 금지**(재현성).
- **`BacktestResult`**: config_fingerprint · equity_curve(list[(date,Decimal)]) · total_return(Decimal) · cagr/sharpe/sortino/max_drawdown(float) · turnover/total_cost(Decimal) · n_rebalances · **n_delisted_liquidations**(가드 발동 증거) · benchmark_returns(dict) · **data_caveats**(cik미해소·합성폐지·1년치 한계 명시).
- **`GuardReport`**: is_sharpe·oos_sharpe·decay_ratio(None if IS≤ε)·is_failed·decay_warning·sensitivity·purge_gap_days·notes.

**돈=Decimal 끝까지 / 통계(Sharpe·CAGR·연환산 무리수)=float, 변환 1곳 격리.** (TopEntry.score=float 선례와 일관)

### 금융 가드 (red-team BLOCKING — 1차 필수)

1. **forward-return 룩어헤드**: 랭킹=as_of(t), **진입=t+1**(동시성 누설 차단). ports 2종 스캔 분리(랭킹용 as_of + 수익실현용 전구간 [t+1,t']).
2. **유니버스 survivorship**: `UniversePort.constituents(as_of)`로만 도출 — 가격파일 존재로 도출 금지(미래상장 포함·폐지 자동제외 = 양방향 편향). "가격행 존재 ≠ 거래가능" 코드 계약.
3. **폐지 회계**: gap(결측·거래정지) ≠ 폐지. **명시적 delisting_event로만 청산** 트리거, `delisting_recovery_rate` 적용. 시계열 단절을 폐지로 추론 금지.
4. **IS/OOS 누수**: 정규화·파라미터는 IS로만 추정·OOS 동결. 워크포워드 창 경계에 `max(lookback,skip)` **purge gap**.
5. **Decimal/float·연환산**: 거래일수 상수 명시(252) + 동적 산출 옵션.
6. **Sabotage 테스트**(기존 패턴): ①미래 데이터 주입→결과 불변(룩어헤드) ②폐지종목 제거→지표 변동(생존편향 발동).

### 1차 범위 vs 결제후

**1차(무료 골격·TDD 합성)**: calendar·ports(2종 스캔)·strategy·costs·engine(리밸·forward-return·폐지청산·비용)·metrics(Decimal/float 경계·등가중 벤치)·**FakeUniversePort 합성폐지**·fingerprint 멱등·validation 창분할/purge 로직·IS/OOS·워크포워드. GuardReport.sensitivity는 인터페이스만(구현 후속). 수치결과 전부 `data_caveats` 미검증 명시.

**결제후(S6 게이트 통과)**: 실제 폐지 이벤트(EODHD delisted+폐지일)·IdentityResolver 실전(ticker_history)·S&P500 historical constituents·워크포워드/민감도 수치 신뢰·표준(1%)/엄격(0.5%) 2시나리오 gap.
