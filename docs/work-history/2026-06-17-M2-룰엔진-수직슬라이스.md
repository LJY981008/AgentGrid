# M2 룰엔진 수직 슬라이스 — 모멘텀 팩터 + Top 랭킹

## 의도 (Why)

무료 1년치 EODHD 데이터셋(9종목·251 거래일, [[2026-06-17-EODHD-미니데이터셋-적재]] 산출)으로
**Top 랭킹 엔진 골격**을 입증한다. data(수집·저장)에 이어 rules(랭킹) 모듈을 처음 세운다.

⚠️ **프로토타입 골격**이다(stock-1st_plan §4.1): 팩터(모멘텀 1종)·룩백·가중치는 후보일 뿐, 최종
팩터셋·가중치는 M2 백테스트(§4.4)가 결정한다. 산출 랭킹은 백테스트 검증 전이므로 알파로 신뢰하지
않는다(과적합 경고). 이 단계의 목적은 "수집→팩터→랭킹→TopEntry" 수직 슬라이스가 도는지 증명하는 것.

## Before

- `src/stockpick/rules/` = `__init__.py`(placeholder docstring) 만 존재. 팩터·랭킹 로직 0.
- data 모듈은 완성(storage·ingest·eodhd). rules 가 data/parquet 를 스캔해야 하나 진입점 없음.

## 구현 (What)

신규 4개 라이브러리 모듈 + 1개 진입점 + 테스트:

| 파일 | 역할 | 라인 |
|---|---|---|
| `rules/_scan.py` | Parquet→수정주가 시계열(DuckDB), **룩어헤드 1차 가드**(`trade_date<=as_of` SQL 필터). ticker→exchange 매핑(Hive 파티션 키) | 189 |
| `rules/factors.py` | 모멘텀 팩터(순수 함수). 누적수익률 `P_end/P_start-1`, **룩어헤드 2차 가드**, skip_recent(reversal 회피), graceful 축소 | 183 |
| `rules/ranking.py` | 점수→TopEntry. 점수 내림차순, rank 1-based, competition ranking(동점), 결정적 2차키(ticker), 거래소별/전체 그룹 | 167 |
| `rules/demo.py` | 진입점 `run_demo`/`main` — 스캔→모멘텀→랭킹→표 출력 | 136 |
| `rules/__main__.py` | `python -m stockpick.rules` 진입 | 10 |
| `tests/test_rules.py` | 합성 시계열 단위 테스트(라이브 0) — 18 케이스 | 253 |

### 핵심 설계 결정

| 설계 결정 | 근거 | 트레이드오프 | 금융 리스크 대응 |
|---|---|---|---|
| 스캔(I/O)과 팩터(계산) 분리 | factors 를 순수 함수로 → 합성 데이터 단위 테스트(라이브 0, 테스트 정책) | 모듈 1개 추가 | 룩어헤드 **2중 방어**(SQL 1차 + 메모리 2차) |

| 동점 = competition ranking(1,1,3) + ticker 2차키 | 진짜 동점을 사용자에 노출 + 재현성(결정적 순서) | — | 재현성 BLOCKING |
| cik="" (EODHD 미제공) | 데이터셋 한계 명시(추측 금지). 후속 EDGAR 매핑 | ticker 로만 식별 | 조용한 누락 금지 |

### ⭐ 룩어헤드 안전성 — sabotage 검증

`test_momentum_lookahead_safety_future_data_ignored`: as_of 이후 데이터(999, 9999)를 추가해도
as_of 점수가 불변임을 단언. **이 테스트가 진짜 미래누설을 잡는지** factors.py 의 `trade_date<=as_of`
필터를 일시 제거(sabotage)해 확인:

```
# 필터 제거 후:
test_momentum_lookahead_safety...  FAIL: 0.2 == 82.325 (미래 9999 누설)
test_momentum_as_of_in_past...     FAIL: 4 == 0.2 (미래 600 누설)
# 필터 복원 후: 전부 PASS
```

→ 공허한 단언이 아니라 **실제 회귀 봉인**임을 입증. 복원 후 재검증 clean.
