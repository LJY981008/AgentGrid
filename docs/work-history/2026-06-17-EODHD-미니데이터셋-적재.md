## 의도/목적 — 왜 이 작업을 하나

M2(Top20 룰엔진/백테스트) 개발을 시작하려면 실제 가격 데이터셋이 필요하다. 지금까지는
어댑터(Tiingo/EODHD)·저장층·검증 게이트가 각각 모킹 테스트로만 검증됐고, 파일럿(`pilot.py`)은
Tiingo 5종목 분할 교차검증 목적이라 데이터셋 생성용이 아니다.

이 작업이 끝나면:
- 소스 무관(DataSource Protocol) **재사용 generic 적재기** `ingest.py` 가 생긴다 — Tiingo/EODHD/
  향후 Sharadar 어느 소스든 (ticker, exchange) 목록을 받아 fetch→저장→누적검증.
- EODHD 무료티어(최신 1년·종목당 1콜)로 섹터·거래소 분산된 미국 ~8종목 미니셋이 `data/parquet/`
  에 적재돼 M2 룰/백테스트가 즉시 스캔 가능.

## 계획

1. `src/stockpick/data/ingest.py` — `ingest_tickers(source, targets, *, base_dir, start, end)`:
   각 (ticker, exchange) 를 `source.fetch_daily_bars` → `write_daily_bars`(exchange별) →
   **누적 expected 로 `verify_parquet`**(TASK-B 소실탐지 재사용). 종목별 행수·기간·게이트 집계 반환.
   빈 결과·부분 실패는 명확 집계·로그(조용한 누락 금지).
2. 실행 진입점(`python -m stockpick.data.ingest`): `configure_logging()` 먼저(httpx 토큰 가드) →
   EodhdSource 주입 → 분산 8종목 적재 → 사람용 표 출력.
3. 모킹 테스트 `tests/test_ingest.py`(라이브 0): FakeSource(일부 0행·일부 정상) → 누적 verify PASS·
   집계 정확·0행 명확 집계·소실 시 FAIL 단언.
4. 컨테이너 라이브 적재 실행 + 검증(ruff/format/mypy/pytest) 전부 통과.
