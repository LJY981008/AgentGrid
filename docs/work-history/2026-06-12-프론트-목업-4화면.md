## 의도/목적 — 왜 이 작업을 하나

기획이 텍스트로만 존재 — 사용자(프로덕트 오너)가 "어떤 느낌인지 감이 안 옴". 백엔드 구현 전에 mock 데이터로 4화면을 먼저 구현해 **와이어프레임 대용**으로 기획을 시각 검증한다.
부수 효과: mock 데이터의 TS 타입이 백엔드 API 응답 계약(DTO) 초안 역할 — 스키마 설계(db-architect) 전에 데이터 모델을 화면 관점에서 한 번 검증.
주의: 디자인 확정 아님 — 구조/플로우/정보 배치 평가용.
