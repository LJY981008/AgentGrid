## 사용자 결정
- 이슈①: **drop**(close<=0·가격 없음·비거래일=원래 누락). 
- 이슈②: **open clamp**(close 실거래가 유효·보존). 잔존 close>high 6,289는 같은 원칙으로 통합.

## 통합 정규화 규칙 (close 불변·순서만 보정·없던 가격 invent 안 함)
```
close<=0 → drop(이슈①)
positives = [close] + ([high] if high>0) + ([low] if low>0)
high' = max(positives); low' = min(positives)   # close(실거래가) 포함하도록 확장
open' = close if open<=0 else clamp(open, low', high')   # carry-forward 아티팩트 제거
```
- 보장: 출력 전 OHLC>0 AND ordering 일관(verify nonpositive+OHLC 양 게이트 PASS). 정상 봉엔 **멱등**(불변). open carry-forward→실가·close>high→high 확장·close<low→low 확장·전부 일관.
