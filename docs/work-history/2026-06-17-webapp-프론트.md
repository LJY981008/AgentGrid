# webapp PWA 대시보드 전체 구현 (영점→5화면)

## 의도 (왜)

CLI로만 동작하던 데이터 파이프라인·룰엔진을 **읽기 위주 PWA 대시보드**로 노출한다. 백테스트 구현
전에 프론트를 먼저 완성해 (1) 기존 기능을 UI로 실행·확인, (2) docs/learning 학습노트를 앱에서
열람한다. 투자 로직(랭킹·점수)은 전부 Python API(단일 진실)이고 프론트는 **표시·트리거만**
한다(webapp-conventions: 투자 로직 프론트 중복 금지).

§4.1 BLOCKING: 랭킹은 백테스트 미검증 = 알파 아님 → 미검증 경고 배너를 **상시(fail-safe)** 노출.

## Before

- `webapp/` 디렉토리 부재(경로만 예약). 프론트 코드 0.
- 소비 대상 API(`src/stockpick/api/`)는 이미 구현됨(health·dataset·ingest·ranking·learning).

## 구현 (What)

스택(tech-researcher 실측 — docs/research/2026-06-17-webapp-stack-버전.md):
Vite 8 / React 19.2 / TypeScript 6 / react-router 7(Data Mode) / vite-plugin-pwa 1.3 /
react-markdown 10(`urlTransform`) / remark-gfm 4 / rehype-slug 6. **recharts 미설치**(score 바는
순수 CSS width% — 백테스트 곡선 착수 시 도입). @types/node 추가(vite.config 의 process.env).

생성 파일(webapp/, src 21개 ts/tsx):
- 스캐폴딩: package.json·tsconfig{,.app,.node}.json·vite.config.ts(vite-plugin-pwa +
  dev proxy /api·/learning-assets→:8000)·index.html·.gitignore·.env.example·public/favicon.svg·
  public/icons/{192,512,512-maskable,apple-touch}(PIL 생성).
- api/: types.ts(models.py 1:1 미러, snake_case·ISO date)·client.ts(fetch 래퍼·ApiError 정규화·
  429/502 분기·learningAssetUrl)·endpoints.ts·useApi.ts(로딩/에러/데이터 3상태 훅, AbortController).
- components/: Layout(모바일 하단 탭바→데스크탑 좌측 사이드바)·common/{StateViews,Badge,
  UnvalidatedWarning}·ranking/RankingTable(거래소별 블록·rank 1부터·score 바)·
  learning/{TopicTree,MarkdownView}.
- pages/: Dashboard(랭킹+경고배지+빈상태 DataPage 유도)·Data(dataset 요약+ingest 데모9·20콜/일
  고지·429 친화·결과표)·Universe(적재 종목 읽기)·Learning(트리+마크다운·urlTransform·?path= 딥링크)·
  Backtest(placeholder §4.1)·NotFound.
- styles.css(다크 테마·CSS 변수·모바일 우선)·main.tsx·router.tsx·vite-env.d.ts.

핵심 설계 결정:
- **urlTransform(react-markdown 10)** 으로 상대경로 재작성(커스텀 rehype 회피): 상대 이미지→
  `${API_BASE}/learning-assets/${dir}/...`, 상대 .md→내부 `/learn?path=`, 절대/프로토콜은 안전
  스킴(http/https/mailto/tel)만 통과(XSS 방어), `<img loading=lazy>`.
- **UnvalidatedWarning fail-safe**: validated===true 일 때만 숨김 → meta 누락(에러·로딩)에도 경고 노출.
- SW(generateSW): 앱셸 precache · /learning-assets CacheFirst · /api/* NetworkOnly(신선도).
- dev proxy 로 same-origin(/api) 호출 → 브라우저 CORS 회피.
