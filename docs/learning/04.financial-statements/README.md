# 재무제표 읽는 법 (재무제표 시리즈)

> 📚 **이 문서 한눈에**
> - **배우는 것**: 재무제표 3종(대차대조표·손익계산서·현금흐름표)이 각각 무엇을 말하는지, 그리고 어떤 순서로 공부하면 막히지 않는지
> - **난이도**: 🟢입문 (이 README는 시리즈 전체의 길잡이 — 표 따라 챕터로 들어가면 됨)
> - **왜 중요(stockpick)**: 정량 룰의 입력값(부채비율·마진·ROE·FCF 등)이 전부 재무제표에서 나온다 — 숫자의 출처를 알아야 룰을 의심할 수 있다

기업의 **생존·수익·실제 현금**을 스스로 판단하기 위한 재무제표 3종 + 보충편. 미국주식 갤러리 연재 시리즈(작성자 _케이네)를 챕터별로 정리했다. 기준은 **미국 시장(미장)**.

> 🖼 각 챕터 하단에 **원문 dcinside 캡처 이미지(총 97장)** 를 작성 순서대로 임베드해 뒀다 (`assets/<챕터>/`). 표·그래프·스크린샷 원본을 그대로 본다.
>
> 🔰 숫자·기준을 곧이곧대로 믿기 전에 → **[초보자 주의사항](../00.caveats.md)** (부채비율 정답·휴리스틱·생존편향 포함).

> 핵심 흐름: **대차대조표**(살아남나) → **손익계산서**(버나) → *감가상각의 유래*(이익은 왜 가공인가) → **현금흐름표**(진짜 돈이 도나) → **연차보고서**(보고서에서 직접 찾기).

재무제표(쉽게: 회사가 1년 동안 어떻게 벌고 쓰고 빚졌는지를 숫자로 적은 성적표)는 크게 3장으로 나뉜다. 이 셋은 따로 노는 게 아니라 **한 회사를 세 각도에서 찍은 사진**이라고 보면 된다.

> 🍞 비유 (일상 비유): 재무제표 3종은 한 사람을 보는 세 가지 방법과 같다. **대차대조표** = 지금 이 사람의 재산·빚 현황(스냅샷), **손익계산서** = 올 한 해 얼마 벌고 썼나(가계부), **현금흐름표** = 통장에 실제로 들어오고 나간 돈(입출금 내역). 가계부상 "벌었다"와 통장에 "찍힌 돈"이 다를 수 있다는 게 핵심 포인트다.

> 🔧 비유 (개발자 비유): 대차대조표는 특정 시점의 DB 스냅샷(상태), 손익계산서는 1년치 트랜잭션 로그를 집계한 리포트, 현금흐름표는 실제 계좌 이체 내역에 가깝다. 회계상 "수익 인식"(발생주의)은 실제 입금과 시점이 어긋날 수 있어서 — 마치 비동기 처리에서 "요청 완료 응답"과 "DB 커밋"이 항상 동시는 아닌 것과 비슷하다. 그래서 현금흐름표로 한 번 더 검증한다.

## 추천 학습 순서 & 난이도

처음 보는 사람은 **위 챕터 표 순서(01 → 06) 그대로** 따라가면 된다. 저자가 "살아남나 → 버나 → 진짜 돈이 도나" 흐름으로 일부러 그렇게 배치했기 때문이다. 시간이 없다면 🟢부터 보고 🔴은 나중으로 미뤄도 된다.

| 순서 | 챕터 | 난이도 | 먼저 알면 좋은 것 |
|---|---|---|---|
| 1 | 01 대차대조표 | 🟢 입문 | 없음 — 여기서 시작 |
| 2 | 02 손익계산서 | 🟡 기본 | 01의 '자본(자기자본)' 개념 (ROE 계산에 쓰임) |
| 3 | 03 회계 혁신 史 | 🟡 기본 | 02의 '순이익' — *왜 순이익이 진짜 돈이 아닌지*를 이 장에서 이해 |
| 4 | 04 현금흐름표 | 🔴 심화 | 03의 감가상각·발생주의 (현금흐름표가 그걸 되돌리는 표라서) |
| 5 | 05 연차보고서 | 🟡 기본 | 01~04 전부 — 실제 보고서에서 위 3종을 직접 찾는 실습 |
| 6 | 06 지침서 모음 | 🟢 입문 | 없음 — 철학·도서 추천이라 아무 때나 |

> 🔰 막히면 멈추지 말고 **[초보자 주의사항](../00.caveats.md)** 을 먼저 보자. 부채비율 '정답'처럼 보이는 숫자가 왜 휴리스틱(쉽게: 정답이 아니라 경험에서 나온 어림 기준)인지, 생존편향(쉽게: 망해서 사라진 회사는 데이터에 안 남아 살아남은 것만 보고 착각하는 함정)이 뭔지 짚어 준다.

## ✅ 핵심 정리

- 재무제표는 한 회사를 세 각도에서 본 사진이다 — **대차대조표**(지금 상태=살아남나) → **손익계산서**(1년 성적=버나) → **현금흐름표**(실제 통장=진짜 돈이 도나).
- 공부 순서는 **01 → 06 그대로** 가면 된다. 저자가 "생존 → 수익 → 진짜 현금" 흐름으로 일부러 배치했다.
- **순이익 ≠ 진짜 들어온 돈**이다. 발생주의·감가상각 때문에 회계상 이익과 현금이 어긋날 수 있어, 현금흐름표(04)로 한 번 더 검증한다 — 그래서 04가 가장 심화(🔴)다.
- 본문의 숫자·기준(피터 린치 25%, ROE 10, '+마마+' 등)은 **저자의 휴리스틱(어림 기준)**이지 검증된 정답이 아니다. 곧이곧대로 믿기 전 [초보자 주의사항](../00.caveats.md)을 본다.
- 전부 **미장(SEC) 기준**이라 한국(코스피·코스닥, DART)에 그대로 적용하면 계정·양식이 달라 어긋난다.
