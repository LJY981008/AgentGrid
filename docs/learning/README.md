## 초보용 추천 학습 순서

처음 공부하는 분이라면 파일 번호 순서(01→04)가 아니라, **개념이 자연스럽게 쌓이는 순서**로 읽는 걸 권한다. 아래는 "겁먹지 않고 → 손에 잡히는 것부터 → 점점 큰 그림으로" 가는 흐름이다.

| 순서 | 노트 | 왜 이 순서인지 | 난이도 |
|---|---|---|---|
| 1 | [00 주의사항](00.caveats.md) | 함정(생존편향·룩어헤드·정의 충돌)을 먼저 알아야 나머지를 안전하게 읽는다. **안전벨트 먼저 매기.** | 🟢입문 |
| 2 | [04 재무제표 읽는 법](04.financial-statements/README.md) | 한 기업을 들여다보는 가장 손에 잡히는 기초. 숫자(매출·이익·부채)를 읽는 눈을 먼저 키운다. | 🟡기본 |
| 3 | [03 SEC 공시의 틀](03.sec-filing-framework/README.md) | 기업이 내놓는 "공식 발표문"을 빠르게 읽는 법. 재무제표를 본 뒤라 무엇을 찾을지 감이 잡힌다. | 🟡기본 |
| 4 | [01 거시 경기 사이클](01.macro-business-cycle/README.md) | 개별 기업에서 시야를 넓혀 경제 전체(경기·금리)와 섹터 흐름을 본다. 추상도가 한 단계 올라간다. | 🔴심화 |
| 5 | [02 연준·재무부 유동성](02.fed-and-treasury/README.md) | 가장 거시·추상적. 시장 전체에 도는 "돈의 양"을 추적한다. 마지막에 큰 그림으로 마무리. | 🔴심화 |

> 🍞 비유: 집을 보는 순서와 같다. 먼저 **계약서 함정**(00)을 확인하고 → **집 내부 상태**(04 재무제표)를 본 뒤 → **등기부·공식 서류**(03 공시)를 떼보고 → **동네 분위기와 학군**(01 경기 사이클) → 마지막으로 **부동산 시장 전체 자금 흐름**(02 유동성)으로 줌아웃한다. 가까운 것 → 먼 것 순이다. (어디까지나 비유)
>
> ⏩ **시간이 없다면**: 최소한 `00 → 04`만 읽어도 "기본 함정 회피 + 한 기업 숫자 읽기"라는 가장 실전적인 두 가지는 챙길 수 있다. 01·02는 배경 맥락이라 나중에 천천히 봐도 된다.

## 출처 관점 주의

- **01·03**: 미국 시장(S&P500·SEC/EDGAR) 기준. 한국 시장(코스피·코스닥) 적용 시 섹터 분류·공시 체계(DART)가 달라 1:1 대응 안 됨.
- **02**: 미국 연준·재무부 유동성 지표. 글로벌 위험자산 전반에 영향이라 한국 주식에도 간접 작용하지만, 직접 신호로 쓰지 말 것.

## ✅ 핵심 정리

- 이 문서는 학습 노트의 **목차이자 길잡이**다. 개별 지식은 각 노트(00~04)에 있고, 여기서는 "무엇이 있고 어떤 순서로 읽을지"만 잡는다.
- **읽는 순서 ≠ 파일 번호**. 초보는 `00 주의사항 → 04 재무제표 → 03 SEC 공시 → 01 거시 사이클 → 02 유동성` 순으로 "가까운 것(개별 기업) → 먼 것(시장 전체)"으로 가는 게 자연스럽다.
- 난이도는 🟢입문(00) / 🟡기본(03·04) / 🔴심화(01·02)로 표시했다. 심화는 추상도가 높으니 기초를 다진 뒤 봐도 늦지 않다.
- 여기 자료는 전부 **교육용 휴리스틱**이지 검증된 알파 소스가 아니다. 룰에 넣으려면 반드시 생존편향·룩어헤드를 통제한 백테스트 검증을 거친다.
- 시간이 없으면 최소 `00 → 04`만이라도 챙기면 "함정 회피 + 한 기업 숫자 읽기"라는 실전 핵심 두 가지는 확보된다.
