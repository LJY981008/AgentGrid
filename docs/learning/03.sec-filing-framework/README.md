# SEC 공시의 전체적인 틀 (EDGAR 공시 빠르게 읽는 법)

> 📚 **이 문서 한눈에**
> - **배우는 것**: ① SEC 제출 유형(무슨 서류냐)을 카테고리로 분류하는 법 ② 8-K의 섹션·아이템 번호(무슨 사건이냐)를 번호만 보고 읽는 법 ③ 여러 공시를 흐름으로 연결해 "지금 무슨 일이 벌어졌는지" 역추적하는 사고법
> - **난이도**: 🟡기본 (개념은 어렵지 않으나 유형/번호가 많아 익숙해지는 데 시간이 걸림)
> - **왜 중요(stockpick)**: 한국 DART와 양식은 다르지만 "공시 신호로 사건을 역추적한다"는 사고 방식은 그대로 이식 가능 — 미국 상장사·해외 사례를 볼 때의 참고 틀.

> 🍞 비유: 공시(disclosure, 쉽게: 회사가 법적으로 의무적으로 공개하는 보고서)는 회사가 외부에 보내는 **공문서 더미**다. 처음엔 다 똑같은 종이 뭉치로 보이지만, 양식 번호(서류 제목)와 항목 번호(내용 분류)만 눈에 익으면 "아, 이건 계약 체결, 저건 임원 교체"처럼 봉투만 봐도 내용을 짐작하게 된다. 이 문서는 그 봉투 읽는 법을 정리한 것이다. (어디까지나 직관을 위한 비유)

> 기업의 공시 내용을 확인하려면 종류가 너무 많고 오래 걸린다. 그래서 **공시의 전체 틀을 분해**해, 자주 쓰는 유형만 추려 빠르게 읽는 법을 정리한 노트.
>
> SEC 제출 양식의 제출 유형은 매우 많아 **자주 활용하는 유형만** 다룬다. (원작자 주: 일부 유형은 이해가 정확하지 않을 수 있음 — 교차검증 권장)

핵심 아이디어: 제출 유형(무슨 서류냐)과 8-K의 섹션·아이템 번호(무슨 사건이냐)가 눈에 익으면, 쏟아지는 공시를 **하나하나 안 읽어도 흐름으로 연결**해 "지금 무슨 일이 벌어졌는지" 답이 빨리 나온다.

> 📚 대상은 **미국 SEC/EDGAR**. 한국은 공시 체계가 DART라 양식·번호가 다르다. 한국 주식 분석에 직접 쓰진 못하고, 미국 상장사·해외 사례를 볼 때의 참고 틀.

**먼저 약어 풀이** (쉽게: 본문에 계속 나오는 기관·시스템 이름):
- **SEC** (Securities and Exchange Commission, 쉽게: 미국 증권거래위원회 — 우리나라 금융감독원에 해당하는 미국의 증권 감독 기관)
- **EDGAR** (쉽게: SEC가 운영하는 공시 서류 전자 열람 시스템 — 한국의 DART에 해당)
- **DART** (쉽게: 한국 금융감독원의 전자공시시스템)

> 🔧 비유: 제출 유형(서류 제목)과 8-K 아이템 번호(사건 분류)의 관계는 백엔드 개발자에게 **HTTP 메서드 + 상태 코드**와 비슷하다. `POST`(서류 종류)만 봐도 "데이터 생성 요청"임을 알듯, `8-K 1.01`만 봐도 "중요 계약 체결"임을 안다. 번호 체계에 익숙해지면 본문을 다 안 읽어도 의미가 잡힌다. (이해를 돕는 비유)

## 챕터 1. 제출 유형 (Filing Types)

"무슨 종류의 서류인가". 카테고리별로 묶었다.

> 🍞 비유: 챕터 1은 **우편함에 꽂힌 봉투의 종류**를 분류하는 단계다. 정기 고지서(정기보고서)냐, 특별 통지서(특정 신고서)냐, 주주 안내문(주주총회)이냐를 봉투 겉면(유형 코드)만 보고 나누는 것. 아래 두 이미지는 원작자가 정리한 전체 유형 표의 원본 캡처이고, 그 아래 텍스트 표들은 그중 자주 쓰는 것만 카테고리별로 풀어 쓴 것이다. (분류를 돕는 비유)

### 기업 정기보고서

(쉽게: 회사가 **정해진 주기마다 의무적으로 내는** 실적·재무 보고서. 시험으로 치면 중간·기말고사 성적표.)

> 🍞 비유: 10-K는 **연간 성적표**, 10-Q는 **분기 쪽지시험 결과**라고 생각하면 쉽다. 유형 코드 뒤의 `/A`(amendment, 쉽게: 수정본)는 먼저 낸 보고서를 고쳐 다시 낸 것. (직관용 비유)
>
> 참고: `NT-10Q`의 **NT는 Notification(통지)** 약자로 "기한 내 못 내겠다"는 지각 사유서 격이다. 정기보고서 자체가 늦어진다는 신호이므로 투자자 입장에선 작은 경고등으로 볼 수 있다.

| 제출 유형 | 설명 | 비고 |
|---|---|---|
| 10-K, 10-K/A | 연례 보고서 | |
| 10-Q, 10-Q/A | 분기 마감 보고서 | |
| NT-10Q | 정해진 기한 내 보고서를 제출하지 못하겠다는 **지연 통지서** | |
| 15-15D, 15F-15D | 보고서 제출 의무가 더 이상 없음을 통지 → **상장폐지 등** | 매우 보기 드뭄 |

### 특정 신고서

(쉽게: 정기 보고서가 아니라 **특정 사건이 생겼을 때 그때그때 내는** 신고서. 8-K가 이 그룹의 핵심이라 챕터 2에서 따로 깊게 다룬다.)

> 🍞 비유: `144`는 내부자(임원·대주주)가 "내 지분을 좀 팔겠다"고 미리 알리는 **매각 예고장**이다. 회사를 잘 아는 사람의 매도 신호라 시장이 민감하게 본다. `6-K`(외국기업)와 `8-K`(미국 기업)는 둘 다 "주요 사건이 발생했다"는 **속보**에 해당한다. (이해용 비유)

| 제출 유형 | 설명 | 비고 |
|---|---|---|
| 144, 144A | 내부자·대주주의 지분 매각 제안 | |
| 6-K, 6-KA (외국기업) | 기업의 현재 주요 사건 보고서 | |
| 8-K, 8-KA (미국 내 기업) | 주요 사건 보고서 | 해당 **섹션·아이템 번호가 많아 챕터 2에 별첨** |

### 주주총회 및 기타 관련

(쉽게: 주주총회 안건과 표결을 둘러싼 서류들. **위임장**(proxy, 쉽게: 주주가 직접 못 가니 "내 표를 대신 행사해 달라"고 위임하는 서류) 관련 양식이 핵심이다.)

> 🍞 비유: 코드 앞자리만 보면 구조가 보인다. `DEF`로 시작하면 **DEFinitive(최종 확정본)**, `PRE`로 시작하면 **PREliminary(예비본, 변동 가능)**. `14A`는 위임장 권유 관련 번호. 그래서 `DEF-14A`는 "주주총회용 최종 확정 위임장"으로 읽으면 된다. 회사가 보내는 **투표 안내문 + 위임장 봉투**라고 보면 직관적이다. (코드 해석용 비유)

| 제출 유형 | 설명 | 비고 |
|---|---|---|
| DEF-14A | 주주총회 안건을 상정하는 **최종 제안서**. 주로 20일 이내 SEC 공시 | 위임장 권유를 하는 **최종 위임장** |
| DFAN(14A~C) | 주주총회 관련 정보 제공·전달 및 투표 독려 | 14A에서 다루지 않는 추가 안건 혹은 제안 |
| DEFN(14A~C) | 주주총회 관련 주주들이 중대한 사안을 결정하는 데 필요한 정보 제공·투표 독려 | 위임장 권유가 **없는** 최종 위임장 |
| DFRN14A | (위와 동) | **수정된** 위임장 |
| DEFR(14A~C) | 주주총회 주요 안건·시간·장소 정보 제공, 특정 안건 정보 제공, 투표 독려 | |

### 합병·인수 관련

(쉽게: 회사를 사고팔거나 합치는 **M&A**(Mergers & Acquisitions, 합병·인수) 관련 위임장 서류. 코드 가운데 `M`이 Merger를 가리킨다.)

> 🍞 비유: 앞에서 본 규칙을 그대로 적용하면 읽힌다. `PREM14A` = `PRE`(예비) + `M`(합병) + `14A`(위임장) → "합병 관련 **예비** 위임장(아직 확정 전, 변동 가능)". `DEFM14A` = `DEF`(최종) + `M`(합병) → "합병 관련 **확정** 위임장". 즉 PRE로 떠봤다가 DEF로 확정하는 순서다. (코드 조합 읽기 비유)

| 제출 유형 | 설명 | 비고 |
|---|---|---|
| DEFM(14A~C) | 합병 또는 인수와 관련된 주주총회 안건 제안 등 | |
| PREM14A | 인수·합병에 관한 **초기 진술서** (초기 예비 진술서이므로 변동 있음) | |

### 증권 발행

(쉽게: 회사가 **새로 주식이나 채권을 찍어 자금을 조달**할 때 내는 등록 서류. 투자자에게는 "주식 수가 늘어나 내 지분이 희석될 수 있다"는 신호라 중요하다.)

> 🍞 비유: 알파벳이 **국적**을, 숫자가 **순번(처음이냐 추가냐)**을 뜻한다. `F-`는 Foreign(외국 기업), `S-`는 미국 기업. 숫자 `1`은 **최초**(IPO, Initial Public Offering — 기업이 처음으로 주식을 일반에 파는 것), `3`은 이미 상장된 회사의 **추가 발행**. 그래서 `S-1`=미국 기업 IPO, `F-3`=외국 기업 추가 발행으로 읽힌다. `S-8`은 좀 특수해서 **임직원에게 줄 주식·옵션**을 등록하는 서류다. (코드 해석 비유)

| 제출 유형 | 설명 | 비고 |
|---|---|---|
| F-1 | 외국 기업이 미국 내에서 일반 투자자에게 **최초 공모(IPO)**. 신주·기타 증권 발행 제출서류 | |
| F-3 | 외국 기업이 미국 내에서 일반 투자자에게 **주식 추가 발행** 제출서류 | |
| S-1 | 기업이 **IPO** 위해 최초로 증권을 등록할 때. 재무 정보·사업 개요·리스크 요인 포함 | |
| S-3 | 상장 기업이 **추가 증권 등록**. 주로 "오퍼링". 방식 다양(사모·전환사채&워런트·선반·ATM·블록·직접 등) | |
| S-8 | 직원에게 제공하는 주식 옵션 또는 특정 증권 | |

### 기타 (투자설명서·효력)

(쉽게: **투자설명서**(prospectus, 쉽게: 증권을 팔기 전 투자자에게 "이런 조건으로 발행합니다"를 알리는 안내서)와 **효력 통지** 관련 서류. 증권 발행이 실제로 굴러가기 직전·직후 단계다.)

> 🍞 비유: `424` 시리즈는 증권 발행의 **상품 설명서**다. `424A`가 큰 그림(포괄 정보)이라면 `424B1~8`은 가격·물량 같은 **구체 조건**을 담은 버전들이라고 보면 된다. `EFFECT`는 "이 서류의 **효력이 발생했다(발효)**"는 도장 격 통지인데, 챕터 3에서 보듯 **언제까지 유효한지(만료일)**를 같이 봐야 함정에 안 빠진다. (안내서 비유)

| 제출 유형 | 설명 | 비고 |
|---|---|---|
| 424A | 424B 시리즈와 달리 **전체적인 정보** 제공 | 포괄적 정보 제공 |
| 424B1~8 | 시리즈에 따라 투자자 정보·매각 방식·기업 실적·추가 정보 등 달라지나, 큰 틀은 **투자설명서**. 424B는 주당 가격·추가매입옵션 등 오퍼링 주요 내용을 상세 기재 | 특정 정보 제공 |
| EFFECT | 어떤 공시(사건·계약 등)에 대한 **효력이 발동함을 통지** | ⚠️ 효력통지의 주의점: 주요 서류상의 계약·옵션 **만료일이 언제인지** 봐야 함 |

### 지분 변동

(쉽게: 누군가 특정 회사 지분을 **5% 넘게** 사들였을 때 내는 신고서. "큰손이 들어왔다"는 신호라 시장이 주목한다.)

> 🍞 비유: 한국의 **5% 룰(대량보유 보고)**과 똑같은 발상이다. 핵심 차이는 **의도**다. `13D`는 경영에 **간섭하겠다**는 적극적 큰손(행동주의 투자자 등 — 본문 "관여하는"), `13G`는 **그냥 투자 목적**의 수동적 큰손(본문 "관여 의도 없는")이다. 같은 5%여도 13D가 뜨면 경영권 분쟁·구조조정 압박 가능성이 있어 더 긴장하고 본다. (의도 구분 비유)

| 제출 유형 | 설명 | 비고 |
|---|---|---|
| 13D | 회사 경영에 **관여하는** 투자자가 5% 이상 보유 시 보고 | 10일 이내 의무 |
| 13G | 회사 경영에 관여 **의도 없는** 일반 투자자가 5% 이상 보유 시 보고 | 10일 이내이나 의무 아님 / 연말 기준 공시 |

## 챕터 2. 섹션·아이템 번호 (8-K Sections & Items)

8-K(주요 사건 보고서)는 "무슨 사건이냐"를 **섹션.아이템 번호**로 분류한다. 번호만 봐도 사건의 성격을 안다.

> 🔧 비유: 8-K의 `섹션.아이템` 번호(예: `1.01`)는 코드의 **로그 레벨·이벤트 코드**와 같다. 로그에서 `ERROR 500`만 봐도 무슨 일인지 알듯, 8-K에서 `1.03`(파산)만 봐도 "큰일 났다"가 바로 잡힌다. 앞자리(섹션 1~9)가 **대분류**, 뒷자리(아이템 .01, .02…)가 **세부 사건**이다. (이벤트 코드 비유)
>
> **섹션 대분류 미리보기** (아래 표들의 길잡이):
> - **섹션 1** = 특정 사건(계약·파산·손상 등) · **섹션 2** = 재무 영향(인수 완료·실적·부채)
> - **섹션 3** = 상장·임원 관련 · **섹션 4** = 회계 감사인 변경 · **섹션 5** = 지배구조(경영권·이사·정관)
> - **섹션 6** = 기타 정보 · **섹션 7~9** = 재무제표/첨부·기타 이벤트·이사회

> ※ **섹션 번호와 아이템 번호는 겹치는 경우가 많다.** (아래 표에 `(item)` 표기는 섹션이 아니라 아이템 번호로 쓰인 경우)
>
> (쉽게: 같은 `3.02`라도 **섹션 번호로서의 3.02**와 **아이템 번호로서의 3.02(item)**가 가리키는 내용이 다를 수 있다는 뜻. 그래서 `(item)` 표기가 붙은 행은 별개로 봐야 한다.)

## 챕터 3. 활용 — 공시 흐름 역추적

당장 3개월 공시만 봐도 8-K가 난무해 뭔 내용인지 판단이 안 선다. 하지만 **제출 유형과 섹션 번호가 눈에 익으면 서류가 줄줄이 연결**된다.

> 🔧 비유: 챕터 1·2가 **개별 함수/이벤트 코드 사전**이었다면, 챕터 3은 그 이벤트들을 **시간순 로그(스택 트레이스)로 이어 붙여 사건의 인과를 재구성**하는 단계다. 각 줄(공시)만 보면 단편이지만, 순서대로 쌓으면 "증자 한 사이클이 돌았다" 같은 전체 스토리가 보인다. (트레이스 비유)
>
> **오퍼링(offering, 쉽게: 회사가 새 주식·증권을 발행해 자금을 모으는 행위 = 한국의 유상증자/증권 발행에 해당)**: 기존 주주에겐 지분 희석 위험이 있어, "지금 이 회사가 증자 사이클의 어디쯤인지"를 공시 흐름으로 읽는 게 핵심이다.

### 예시 ① 오퍼링 완료 흐름 (EDGAR 타임라인)

(쉽게: 아래는 한 회사가 **증권 등록 → 계약 → 투자설명서 → 효력 발생**으로 이어지는 오퍼링 4단계를 EDGAR 타임라인에서 잡아낸 예시다. 날짜 옆 코드가 모두 챕터 1·2에서 본 그 유형/번호들이다.)

![EDGAR 공시 타임라인 예시](10.example-edgar-filing-trail.png)

```
9/18  S-3      (증권 등록 — 오퍼링 준비)
   ↓
9/25  8-K 1.01 (Entry into a Material Definitive Agreement — 계약 체결)
   ↓
9/25  424B5    (투자설명서 — 오퍼링 조건 확정)
   ↓
9/25  EFFECT   (효력 통지 — 효력 발생)
```

자세한 내용은 따로 봐야 하지만, 이 순서만 봐도 "**오퍼링이 완료됐구나**"라는 답이 나오면서 서류가 바로바로 연결된다.

> 🍞 비유: 위 타임라인을 한 줄 스토리로 풀면 — `S-3`(증자할 수 있게 미리 등록) → `8-K 1.01`(자금 조달 계약을 맺음) → `424B5`(주당 가격·물량 같은 조건을 공개) → `EFFECT`(법적으로 발효, 실제 발행 가능). 즉 **"준비 → 계약 → 조건 확정 → 발효"**의 한 사이클이다. 같은 날(9/25)에 세 건이 몰린 것도 "한 번에 마무리 지었다"는 단서다. (사이클 비유)

### 예시 ② 효력통지 역추적 (선반등록·추가매입옵션)

(쉽게: **효력통지(EFFECT)**가 왜 함정인지 보여주는 예시. "효력이 발생했다"만 보고 끝내면 안 되고, **그 효력이 언제까지 유효한지(만료일)**까지 봐야 숨은 추가 발행 가능성을 잡아낼 수 있다는 이야기.)

> **선반등록(shelf registration, 쉽게: 증권을 미리 등록만 해두고 "필요할 때 꺼내 파는" 방식 — 책장(shelf)에 올려두고 두고두고 발행)**: 한 번 등록으로 여러 번 나눠 팔 수 있어, 투자자는 "언제든 추가 물량이 나올 수 있다"고 경계해야 한다.
> **추가매입옵션(쉽게: 인수자가 "원하면 같은 조건으로 더 살 수 있는" 권리 — 초과배정·오버앨럿먼트 개념)**: 발동되면 발행 주식이 더 늘어 지분이 추가로 희석된다.

![효력통지 예시 (EDGAR 전문검색)](11.example-effectiveness-notice.png)

> 효력통지를 빨간 글씨로 강조한 이유:

- 예시(원작자가 "어제 급등주"라 칭한 종목)의 경우, **22년 9월에 올린 효력통지서**를 보면 **24년 9월 24일 투자설명서도 효력 발생**된다고 적혀 있음.
- 내용: "특정 주식을 매입할 수 있는 권리 부여, **25년 7월까지**".
- **선반(shelf) 등록 바꿔치기**나, 오퍼링에서 **추가매입옵션 발동** 같은 경우가 많다.
- 그래서 **오퍼링은 반드시 효력통지 확인을 통해 역추적**해봐야 한다는 게 핵심.

> 메모(원작자): 오퍼링은 여러 잡주의 오퍼링 방식을 더 많이 접하고 확신이 서야 정리 가능. (이 챕터는 추가 검증 여지가 있는 영역)

---

## ✅ 핵심 정리

- **공시는 봉투(제출 유형)와 항목 번호(8-K 섹션·아이템)로 분류된다.** 둘만 눈에 익으면 본문을 다 안 읽어도 "무슨 서류 + 무슨 사건"이 즉시 잡힌다.
- **제출 유형 코드는 조합으로 읽는다**: `DEF/PRE`(확정/예비), `M`(합병), `F-/S-`(외국/미국), 숫자 `1/3`(최초/추가). 예: `PREM14A` = 합병 관련 예비 위임장.
- **8-K 번호는 앞자리=대분류, 뒷자리=세부 사건**. 같은 번호라도 `(item)` 표기가 붙으면 별개 항목이니 영문 제목으로 구분한다.
- **레드 플래그 항목**을 기억해 두자: `1.03`(파산), `4.02`(과거 재무제표 신뢰 상실), `3.01`(상장 폐지 통지) 등은 강한 경고 신호.
- **공시는 한 줄씩이 아니라 흐름으로 읽는다.** 오퍼링 = `S-3 → 8-K 1.01 → 424B → EFFECT` 한 사이클. 특히 **효력통지는 만료일까지** 봐야 숨은 추가 발행(선반등록·추가매입옵션)을 놓치지 않는다.
- **대상은 미국 EDGAR**. 한국은 DART라 양식·번호가 다르지만, "공시 신호로 사건을 역추적한다"는 사고법은 그대로 가져올 수 있다.

## 🧠 셀프 체크

1. `8-K`에서 `1.03`과 `4.02` 항목은 각각 어떤 사건이고, 투자자에게 왜 강한 경고 신호인가?
2. 제출 유형 `PREM14A`와 `DEFM14A`는 코드 구조상 무엇이 다른가? (앞자리 `PRE`/`DEF`와 가운데 `M`의 의미로 설명해 보라.)
3. 오퍼링 흐름에서 `EFFECT`(효력통지)를 볼 때 "효력이 발생했다"만 확인하면 왜 부족한가? 추가로 무엇을 봐야 하는가?

## stockpick 연결 메모

- 미국 EDGAR 체계라 한국 주식 정량 룰에 직접 투입 안 됨. 한국은 **DART**(전자공시)로 별도 틀 필요.
- 다만 "공시 신호로 사건을 역추적한다"는 **사고 방식**은 한국에도 이식 가능 — 유상증자·전환사채·최대주주 변경 공시 흐름 읽기 등.
- 향후 해외 사례 분석이나 ADR/해외 상장 한국 기업을 볼 때의 참고 레퍼런스.
