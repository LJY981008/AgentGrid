# 05 백테스트 검증과 운영 모델

> ⚠️ 교육용·방법론 노트(금융 BLOCKING). "게이트 통과 = 수익 보장"으로 오인 금지 — 이 도메인 최악의 실수. 시변 로드맵은 메모리(`project-remaining-roadmap`)·[[plans/작업재개-RESUME|RESUME]] 참조(이 문서는 불변 방법론만).

stockpick 핵심 설계 = **백테스트(도구)로 신뢰할 룰을 거르고, 투자 판단은 사람**. 이 노트는 그 운영 모델과 룰 반복 워크플로우를 정리한다.

## 1. 게이트 통과가 의미하는 것 (필요조건·충분조건 아님)

S6-b 신뢰성 게이트(ADR-009·G-1~G-8) 통과 = **과거에 강건했다는 최소 자격**:
- out-of-sample(검증 안 쓴 기간)에서도 버팀(decay≥0.5),
- 거래비용 올려도 버팀(5/10/15bps),
- 폐지종목 포함(생존편향 없이) 등가중 벤치를 이김.

= "명백히 깨지거나 과적합된 룰은 아니다" 정도. **통과는 필요조건이지 충분조건 아님.**

### 통과해도 미래 수익 보장 안 되는 이유 (BLOCKING)
1. **과거 ≠ 미래** (1원칙). 시장 국면 바뀌면 먹히던 룰이 멈춤. 백테스트는 과거 replay.
2. **과적합 잔존**. 워크포워드로 걸러도, 룰 하나 골라 테스트한 것 자체에 data-snooping 편향(100개 시도해 best면 우연).
3. **실행 격차**. 슬리피지·세금·유동성(상위N이 실제론 그 가격에 못 사기도)·백테스트는 이상적 체결 가정.
4. **단일 팩터 취약**. momentum 하나는 fragile. 진짜 전략은 다팩터 분산.

## 2. 역할 분담 (자동 수익기계 아님)

| 백테스트(기계) | 사람(사용자) |
|---|---|
| 룰이 과거에 강건했나 **검증**(생존편향·룩어헤드·과적합·비용 가드) | 통과 룰 중 **뭘 살지** 선별 |
| Top20 정량 후보 산출 | 시장 상황·뉴스 **정성 판단** |
| — | **Top5 분산·비중·진입시점·추적·보정** |

기획 흐름: `정량 룰 Top20 → 사용자 Claude 세션 토의로 수동 Top5(정성 보정) → 분산투자 → 추적·보정으로 안정화`. 통과한 룰은 **투자 판단의 입력**이지 오토파일럿 아님. LLM 토의도 알파 소스 아니라 정성 보정(stock-1st_plan §4.1).

⚠️ 전제: **검증된 룰이 실제 확보돼야** 이 그림 성립. 게이트 fail이면 "아직 신뢰할 룰 없음" → 룰 개선부터.

## 3. 도구 vs 룰 — 무엇을 "계속 발전"시키나

- **백테스트 엔진/게이트 = 도구**(JUnit 같은 테스트 프레임워크). 한 번 잘 만들고 **안정 유지**(버그·최적화만). 매번 다시 안 짬.
- **발전 대상 = 투자 룰**. momentum 단일 → 다팩터(재무 ROE/PB 결합) → 룰을 바꿈 → **안정된 게이트로 재검증**.
- **운영(계속 도는 것)**: ① 데이터 갱신(증분) ② 주기적 재검증(룰 decay) ③ 실투자 추적·보정.

→ "백테스트를 발전"이 아니라 **"백테스트(도구)로 룰을 발전·검증"**.

## 4. 룰 반복 워크플로우 — 매번 8시간 아님 (2단)

| 단계 | 무엇 | 시간 | 언제 |
|---|---|---|---|
| **개발 중 빠른 체크** | 단일 백테스트·부분기간·샘플·1폴드 | 초~수분 | 룰 만질 때마다("가망 있나?") |
| **최종 게이트** | 전체 64년·10폴드·3비용 | ~8hr | 후보 확정 시 1회(공식 validated) |

룰 100번 만져도 빠른 체크 100번 + 게이트 1번. **8hr × 100 아님.**

### 게이트 8hr 자체 단축 레버
1. **병렬화** ⭐ — ~60개 시뮬(10폴드×2×3비용)은 대부분 독립. 순차라 8hr(메모리 13GB/시뮬 탓). 메모리 감축하면 코어 수만큼 병렬 → 8hr÷N.
2. **메모리 근본 감축**(memray·peak ~13GB native) → 병렬 + 호스트 안전 동시 해결.
3. **앵커드 IS 재사용**(폴드 간 겹치는 과거 구간 캐싱)·**부분 재계산**(파라미터만 바뀌면 중간결과 재활용).

⚠️ 현 상태: 빠른-체크 경로·병렬화·메모리 감축 **미구현(백로그)**. 게이트는 all-or-nothing(8hr). 룰 반복을 자주 할 거면 이 셋이 투자 대비 효율 큼.

## 핵심 한 줄
**검증된 룰을 백테스트(도구)로 확보 → 나머지(선별·분산·추적)는 사람.** 통과는 "신뢰하고 써볼 자격"이지 수익 보장 아님. 도구는 안정 유지, 발전은 룰·데이터·추적.
